# TONE3000 功能对照

2026-10-19，通过本机已打开的官方独立软件 0.0.12 观察浏览页、筛选区、音色块与 Info 详情，并交叉核对[官方指南](https://www.tone3000.com/guides/tone3000-plugin)和[官方源码](https://github.com/tone-3000/tone3000-plugin)。本轮优先对齐用户提出的在线音色浏览、详情和加载；下表不把新增卡片等同于整套音频引擎已对齐。

## 音色浏览与载入

| 功能 | 官方软件观察 | ToneDock 0.4.0 实现 |
|---|---|---|
| 音色识别 | 封面、名称、设备、格式与 A2 标记 | 异步封面、无图时设备图形、名称、设备、格式；API 明确提供时显示架构 |
| 热度 | 下载量；详情另有收藏量 | 列表与详情均显示下载、收藏和捕获数；悬停可看完整数字 |
| 作者 | 头像、作者名、认证与发布时间 | 同时显示头像、认证与发布时间 |
| 排序 | Best match / Trending / Popular / Newest / Oldest | 分别映射官方五种排序；保留独立名称，不捏造热度分数 |
| 筛选 | 设备、格式、标签、型号、作者、认证、校准 | 对应筛选，增加 A2 / A1/Custom 选择；标签/型号/作者可搜索选择，活动项可逐一清除 |
| 个人音色 | 最近使用、远端收藏、自己创建 | 远端收藏/创建/下载记录，加本地跨会话最近使用 |
| 分页 | 上页、下页与页数 | 上页、下页、API 页数；另可继续追加结果 |
| 详情 | 图片、说明、设备、标签、许可与链接 | 宽屏详情面板，说明可滚动，保留完整元数据与官网入口 |
| 收藏 / 分享 | 同步 TONE3000 收藏、复制音色链接 | 相同入口；仅用户主动点击时改变远端收藏，失败保留原状态 |
| 捕获 | 首次点击音色载入默认捕获，块内再切换 | 单击先看详情，双击或按钮加载；加载后捕获选择器和前后箭头直接替换原位置 |
| 多捕获 / 架构 | 当前官方主要加载 A2 与 IR | 合并 A2 与 A1/Custom 模型，保留捕获名称、架构与大小字段；音频格式边界见 README |
| 布局 | 独立浏览页，返回链路 | 宽屏图文浏览；可随时切换并排链路，拖动替换或新增 |
| 未登录预览 | 热门精选最多 10 条，可筛设备；搜索与加载需登录 | 同样通过公开 Trending 入口预览图文与说明；完整搜索、捕获和加载需登录 |
| 图片与离线 | 图片异步加载；下载的模型可离线播放 | 图片在工作线程获取、解码、缩放；内存最多 128 项，磁盘最多 256 张缩略图；离线模型、预设与最近使用元数据保留 |

下载量来自 `downloads_count`，是 API 提供的下载次数，不冒充独立用户人数。混合架构的列表按 API 流与当前取回结果排序；未读取页的全局名次不作保证。相同音色按 ID 去重，捕获详情以实际返回并去重后的模型为准。

## 仍有的整机差异

| 功能 | ToneDock 当前状态 |
|---|---|
| 独立双通道、分支、声像、Solo、极性翻转、自动对齐/平衡、Spread | 当前为串行单链，尚未对齐 |
| 调音器、复音移调、MIDI 映射及预设切换 | 尚未实现 |
| 每块输入/输出/干湿比与六段参数 EQ | NAM 目前提供电平；可另外放置内置 EQ，尚未等同官方每块控制 |
| 校准、自动响度归一化、A2 Lite/Full、过采样和多核调度 | 尚未对齐；“已校准”筛选只筛选网站数据，不代表音频引擎已经校准 |
| 预设浏览库、工厂预设、可携带模型字节的预设、全局撤销/重做 | 当前提供预设文件保存/打开；其余尚未对齐 |
| 插件格式 | 当前独立版 / VST3 / macOS AU；未提供其他格式 |

ToneDock 已有最多 16 个串行内置效果、中文一致界面、NAM A1/Custom 兼容、Windows 免安装 EXE / ZIP。它们是明确实现的能力；是否优于官方需要结合具体使用流程和实测，不能从功能数量或下载热度推断音质。

## 验证方式

新增自动化覆盖元数据解析、准确/缩写数字、日期、图片解码与缓存上限、最近使用去重、重复模型补充封面但保留用户编辑、远端收藏成功/失败/退出后的回调、宽屏和紧凑目录布局。CI 从实际 ZIP 运行 EXE，生成含明确夹具标记的图文目录预览。真实账号另通过 `--catalog-check` 检查服务器元数据、真实封面和头像、下载、模型校验及音频图准备；验收须以对应提交的 Actions 和本机 JSON 报告为准。
