## 0.3.0 开发验收

2026-10-18。当前为开发版，**尚未标记为可发布版本**；以下实测不等同于完整目录 API 已获生产接入授权。

- `e5deb3c` 的 [Windows 原生作业](https://github.com/wjwpoi/ToneDock/actions/runs/39138361768/job/117707455647) 已通过编译、核心测试、便携包依赖审计和 ZIP 内 EXE 启动，生成效果链、长链小窗口、设备与在线目录四个预览。
- 真实账号通过应用自身的 DPAPI 登录状态，搜索 Fender NAM 得到首批 42 个去重音色；自动下载音色 `88775`，后台校验、入库及音频图准备成功。使用独立测试库与下载缓存，不覆盖用户会话，也不导出令牌。
- 原生窗口全格式目录首批显示 45 个音色，点击「加载更多」后显示 89 个；将 Fender 在线行拖至已有 NAM 卡片后载入成功，链路保持四个位置。
- 自动化新增 A2 / A1 合并、分页、429 原子失败与重试、过期回调、目标已删除、最新请求优先、坏模型保留旧链等检查。后续提交加入双击替换同类位置与预设恢复取消请求，须以对应提交的 [Actions](https://github.com/wjwpoi/ToneDock/actions/workflows/tonedock.yml) 结果确认。
- 此前 Windows 本地 Quantum ES ASIO 已以输入 1、输出 1/2、48 kHz / 128 采样点打开，用户确认吉他正常出声。新版本每次更新的驱动打开、听感和 DAW 验收仍须分别记录。
