# ToneDock Windows 便携版

解压整个 ZIP，双击根目录的 **ToneDock.exe**，无需安装，也无需安装 Visual C++ 运行库。请先解压再运行。独立下载的 EXE 也能直接运行。

## 开始弹奏

1. 打开「设备」页，选择声卡驱动；Windows 专业声卡优先使用厂商 ASIO 驱动。
2. 「乐器输入」选择吉他所在的单声道通道；「耳机 / 音箱输出」选择对应立体声通道对。Quantum ES 2 前面板乐器口为输入 1，耳机跟随主输出 1/2。
3. 返回「效果链」，导入 NAM / IR。先选中要更换的 NAM 或箱体 IR 卡片，再选择库中的模型，点击「加载模型」。未选中同类卡片时会使用链中的第一个同类位置。
4. 横向拖动卡片排序，滚动条浏览长链；上方总览可跳转到全部 16 个位置。下方固定参数区编辑当前效果。支持复制、前移、后移、旁通和删除。

模型库、账号与设置保存在当前用户的 `%APPDATA%\ToneDock`，升级 EXE 会继续使用已有数据。若需自行指定数据目录，可设置环境变量 `TONEDOCK_DATA_DIR`；账号令牌仍由 Windows DPAPI 保护。分发包不含任何账号、个人配置或第三方模型权重。

## 可选插件与网页唤起

- `plugins/ToneDock.vst3` 为 DAW 插件，按需复制到用户 VST3 目录或 DAW 扫描目录。独立版无需复制此插件。
- 需要注册 `tonedock://` 网页链接时，在当前目录运行 `powershell -File .\register-protocol.ps1 -Executable .\ToneDock.exe`。此操作仅注册当前用户，无需管理员权限；移动文件夹后需重新注册。普通运行无需注册。
- TONE3000 通过应用内连接账号，首次需填写公开的 `t3k_pub_...` Key；无需 secret key。

便携版尚未做商业代码签名。文件完整性可用同次发布的 SHA256SUMS.txt 核对。完整源码、构建提交、依赖许可见 manifest.json 与 licenses/。声卡的厂商驱动仍需正常安装。
